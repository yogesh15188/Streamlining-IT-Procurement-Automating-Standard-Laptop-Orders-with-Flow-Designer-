# Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

Welcome to the *Streamlining IT Procurement* project repository!

## About The Project

This project focuses on automating the standard laptop ordering process within IT procurement using Flow Designer. It aims to reduce manual intervention, accelerate approval and fulfillment cycles, and provide a seamless catalog experience for end-users requesting standard hardware.
